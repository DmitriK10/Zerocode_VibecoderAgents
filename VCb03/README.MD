📊 Data Analyzer with LLM Integration
Веб-приложение для загрузки табличных данных (Excel, CSV, PDF), их визуализации и аналитики с помощью языковых моделей (YandexGPT, ProxyAPI). Проект построен на React (фронтенд) и Flask (бэкенд), следует принципам SOLID, легко расширяется.

🚀 Возможности
Загрузка файлов в форматах .xlsx, .xls, .csv, .pdf

Автоматическое извлечение таблиц из PDF (с выбором страницы)

Интерактивная таблица с пагинацией (показ по 100 строк)

Базовый анализ данных (суммы, уникальные значения, типы колонок)

Анализ данных нейросетью:

YandexGPT (через Яндекс.Облако)

ProxyAPI (OpenAI-совместимый, поддерживает GPT-4o-mini и другие модели)

Кэширование загруженных данных на сервере (file_id)

Чистый, расширяемый код (SOLID, DTO, фабрика анализаторов)

🔧 Установка и запуск
Предварительные требования
Python 3.10+ (с pip)

Node.js 16+ (с npm)

Шаг 1: Клонирование репозитория
bash
git clone <repository-url>
cd project-root
Шаг 2: Настройка бэкенда
Перейдите в папку бэкенда (если она отдельно, но в нашей структуре корень – это backend):

bash
cd backend   # или просто оставайтесь в корне, если структура такая
Установите зависимости Python:

bash
pip install -r requirements.txt
Создайте файл .env на основе .env.example:

bash
cp .env.example .env
Отредактируйте .env, вставив свои ключи:

YANDEX_API_KEY и YANDEX_FOLDER_ID – для YandexGPT.

PROXY_API_KEY – для ProxyAPI (остальные параметры уже заданы по умолчанию).

Запустите бэкенд:

bash
python pdf_server.py
Сервер запустится на http://localhost:5000.

Шаг 3: Настройка фронтенда
Перейдите в папку фронтенда:

bash
cd frontend
Установите зависимости Node:

bash
npm install
(Опционально) создайте файл .env для фронтенда, если нужно изменить адрес бэкенда (по умолчанию http://localhost:5000):

env
REACT_APP_API_URL=http://localhost:5000
Запустите фронтенд:

bash
npm start
Приложение откроется на http://localhost:3000.

Шаг 4: Использование
На странице загрузите файл (Excel, CSV или PDF) через кнопку «Выберите файл».

Нажмите «Загрузить».

После загрузки отобразится таблица с первыми 100 строками, кнопка «Показать ещё 100» и базовая аналитика (диаграммы).

Выберите модель анализа (YandexGPT или ProxyAPI) в выпадающем списке.

Нажмите «Проанализировать данные» – результат от нейросети появится в блоке «Анализ от нейросети».

⚙️ Переменные окружения
Создайте файл .env в папке бэкенда со следующим содержимым:

ini
# YandexGPT (Яндекс.Облако)
YANDEX_API_KEY=ваш_API_ключ_сервисного_аккаунта
YANDEX_FOLDER_ID=ваш_id_каталога_в_яндекс_облаке

# ProxyAPI.ru (OpenAI-совместимый API)
PROXY_API_KEY=ваш_ключ_из_ProxyAPI
PROXY_BASE_URL=https://api.proxyapi.ru/openai/v1
PROXY_MODEL=gpt-4o-mini   
🧠 Как это работает
Бэкенд
/upload – принимает файл, определяет формат, читает данные, сохраняет в кэш и возвращает первые 100 строк + file_id.

/analyze – принимает file_id или table_data, выбирает анализатор по model, отправляет первые 15 строк в LLM и возвращает отчёт.

Анализаторы
Все анализаторы наследуют BaseHTTPAnalyzer, реализуют методы для формирования запроса и извлечения ответа.

Фабрика создаёт нужный анализатор по имени модели.

Фронтенд
Компоненты разделены по ответственности: таблица, блок анализа, выбор модели.

API-вызовы вынесены в отдельный модуль api.ts.
