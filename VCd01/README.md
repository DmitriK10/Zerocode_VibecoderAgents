# 🤖 Telegram-бот на CrewAI с локальной LLM (Ollama)

Этот проект представляет собой Telegram-бота, интегрирующего многоагентные системы (CrewAI) для выполнения интеллектуальных задач с использованием **локальной большой языковой модели (LLM)** через Ollama.  
Ранее использовался удалённый API (ProxyAPI), теперь все вычисления производятся на вашем компьютере без передачи данных в облако.

## 🚀 Возможности

- **История ИИ**: создаёт хронологический обзор ключевых событий за последние 10 лет с аналитикой и прогнозом.
- **История ИИ с фактчекером**: дополнительно проверяет факты через поиск в интернете (DuckDuckGo).
- **SEO-анализ сайта**: сканирует страницу, извлекает мета-теги, заголовки, ключевые слова и выдаёт рекомендации.
- **Произвольная задача**: позволяет задать любой вопрос или тему для исследования.

Все задачи выполняются локально с помощью выбранной модели Ollama (например, `deepseek-r1:8b`).

## 📦 Требования

- Python 3.10+
- [Ollama](https://ollama.com/download) установлена и запущена
- Telegram-бот (создаётся через [@BotFather](https://t.me/botfather))
- Достаточно оперативной памяти для выбранной модели (рекомендуется ≥8 ГБ для моделей 7–8B)

## ⚙️ Установка и настройка

### 1. Установите Ollama и загрузите модель

Скачайте и установите Ollama с [официального сайта](https://ollama.com/download).  
После установки откройте терминал и загрузите модель (например, `deepseek-r1:8b`):

```bash
ollama run deepseek-r1:8b
Дождитесь завершения загрузки. Модель будет доступна по адресу http://localhost:11434.

Для более быстрой работы можно использовать gemma3:1b, но качество ответов будет ниже.

2. Клонируйте репозиторий и настройте окружение
bash
git clone <your-repo>
cd crew_ai_history
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
pip install -r requirements.txt
3. Создайте файл .env (скопируйте из .env.example)
Укажите свои настройки:

env
# Локальная LLM через Ollama
OPENAI_API_KEY=ollama
OPENAI_API_BASE=http://localhost:11434/v1
OPENAI_MODEL_NAME=deepseek-r1:8b

# Telegram бот
BOT_TOKEN=ваш_токен_бота_от_BotFather

CREWAI_TELEMETRY_ENABLED=false
🏃 Запуск
bash
python telegram_bot.py
После запуска бот будет доступен в Telegram.

📌 Использование
Отправьте /start или /menu, чтобы увидеть главное меню.

Нажмите на одну из кнопок:

История ИИ (быстро) – без проверки фактов.

История ИИ (с проверкой) – с фактчекером (дольше).

SEO-анализ сайта – затем введите URL.

Произвольная задача – затем напишите свой запрос.

Результат придёт в виде текстового сообщения или файла (если длинный).

🛠 Структура проекта
agents_runner.py – создание и запуск агентов CrewAI, фабрика LLM.

telegram_bot.py – реализация Telegram-бота.

ai_history_crew.py – вспомогательный скрипт для тестирования без бота.

.env – конфигурация (ключи API, модель).

requirements.txt – зависимости.

test_agents_runner.py – модульные тесты.

🐞 Отладка
Убедитесь, что Ollama запущена и модель загружена:
curl http://localhost:11434/api/tags

Запустите ai_history_crew.py для проверки работы агентов без Telegram:

bash
python ai_history_crew.py
📝 Примечания
Поиск в интернете выполняется через DuckDuckGo (бесплатно, без ключей).

Для SEO-анализа используется ScrapeWebsiteTool из crewai-tools.

Все сетевые запросы имеют повторные попытки и увеличенные таймауты для стабильности работы с локальной моделью.
