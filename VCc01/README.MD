📋 Проект: Telegram-бот для сбора анкет с резервным копированием в PostgreSQL, Excel и SQLite
Данный проект представляет собой Telegram-бота на pyTelegramBotAPI, который проводит опрос пользователей (ФИО и дата рождения) и сохраняет полученные данные одновременно в три хранилища:

PostgreSQL (удалённая основная БД на хостинге alwaysdata),

Excel-файл (локальный бэкап в формате .xlsx),

SQLite3 (встроенная локальная БД).

Проект создан в учебных целях для демонстрации работы с базами данных, принципов SOLID и модульной архитектуры.

🚀 Основные возможности
📝 Интерактивный опрос: бот задаёт два вопроса — ФИО и дата рождения.

💾 Автоматическое сохранение ответов в PostgreSQL, Excel и SQLite.

📊 Просмотр последних 5 записей из PostgreSQL через команду /show_data.

🔄 Резервное копирование: данные дублируются в Excel и SQLite на случай потери доступа к основной БД.

🛡️ Устойчивость к сетевым сбоям: реализованы повторные попытки подключения к PostgreSQL.

📁 Чистая архитектура с разделением ответственности (SOLID).

🛠️ Установка и настройка
1. Клонирование репозитория (или создание файлов)
Скопируйте все файлы проекта в локальную папку.

2. Создание виртуального окружения (рекомендуется)
bash
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
.venv\Scripts\activate         # Windows
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Настройка переменных окружения
Создайте файл .env в корне проекта (на основе .env.example) и заполните его своими данными:

text
BOT_TOKEN=ваш_токен_от_BotFather
DB_HOST=postgresql-ваш_аккаунт.alwaysdata.net
DB_PORT=5432
DB_NAME=имя_вашей_базы
DB_USER=пользователь_базы
DB_PASSWORD=пароль_базы
EXCEL_FILE=backups/users_backup.xlsx
SQLITE_FILE=backups/users.sqlite
5. Подготовка базы данных PostgreSQL
Зарегистрируйтесь на alwaysdata.com.

Создайте базу данных PostgreSQL и пользователя с полными правами.

Создайте таблицу users со следующей структурой (можно выполнить через phpPgAdmin):

sql
CREATE TABLE public.users (
    id SERIAL PRIMARY KEY,
    full_name text NOT NULL,
    summ real,
    card_num bigint,
    birthday date
);
Обратите внимание: поле card_num должно быть типа bigint, так как мы генерируем 16-значные номера карт. Если вы хотите хранить их как integer, измените диапазон генерации в коде.

6. Запуск бота
bash
python bot.py
После запуска в консоли появится сообщение 🚀 Бот запущен.... Бот готов к работе.

📱 Команды бота
Команда	Описание
/start	Приветственное сообщение и список доступных команд.
/survey	Запуск опроса: бот задаёт два вопроса (ФИО и дата рождения в формате ДД.ММ.ГГГГ).

🔧 Технические детали
Принципы SOLID в архитектуре
S (Single Responsibility): каждый модуль отвечает за одну задачу (bot.py – управление диалогом, database.py – PostgreSQL, excel_backup.py – Excel, sqlite_backup.py – SQLite, config.py – настройки).

O (Open/Closed): классы открыты для расширения (можно добавить новое хранилище, реализовав метод save_user_data), но закрыты для изменения.

L (Liskov Substitution): все классы хранилищ имеют одинаковый интерфейс save_user_data, что позволяет их взаимозаменять.

I (Interface Segregation): каждый класс предоставляет только необходимые публичные методы.

D (Dependency Inversion): высокоуровневый модуль (бот) зависит от абстракций (методов сохранения), а не от конкретных реализаций.

Работа с PostgreSQL
Используется библиотека psycopg2-binary.

Соединение создаётся при каждом запросе (не постоянное) для избежания таймаутов.

Реализованы повторные попытки (до 3 раз) с экспоненциальной задержкой при ошибках.

Настроены keepalives и таймауты для стабильности.

Резервное копирование в Excel
Используется openpyxl.

При первом запуске создаётся файл с заголовками.

При каждом сохранении добавляется новая строка, id вычисляется как max(id)+1.

Резервное копирование в SQLite
Используется встроенный модуль sqlite3.

Таблица создаётся автоматически при первом запуске.

Хранит те же данные, что и PostgreSQL, в локальном файле.

Обработка SSL-ошибок
Для обхода проблем с SSL-сертификатами (часто возникающих на Windows с антивирусами) в коде используется кастомный HTTPAdapter, отключающий проверку SSL. Это временное решение для отладки, не рекомендуется для продакшена. В реальных условиях следует использовать корректные сертификаты через certifi.

🐛 Возможные проблемы и их решение
Проблема	Решение
Ошибка подключения к PostgreSQL (server closed connection)	Проверьте, что ваш IP-адрес добавлен в белый список alwaysdata. Проверьте логин/пароль в .env.
Ошибка SSL при запуске бота (SSLEOFError)	Используйте VPN, отключите антивирус или обновите сертификаты (pip install --upgrade certifi). В коде уже реализован обход SSL для отладки.
Ошибка column "card_num" does not exist	Проверьте имя столбца в таблице PostgreSQL; в коде используется card_num. Если имя другое – измените запрос в database.py.
Ошибка null value in column "id"	Убедитесь, что столбец id определён как SERIAL PRIMARY KEY (автоинкремент).
Номер карты не помещается в integer	Используйте bigint в PostgreSQL или уменьшите диапазон генерации в коде.
📝 Дополнительные замечания
Для работы с Excel файлами может потребоваться установка openpyxl (уже включена в requirements.txt).

Бот сохраняет данные синхронно во все три хранилища; если одно из них недоступно, остальные продолжат работу, но пользователь получит сообщение об ошибке.

Валидация даты минимальна – ожидается строгий формат ДД.ММ.ГГГГ. При желании можно расширить, добавив нормализацию ввода.
