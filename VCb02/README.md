# 🤖 Telegram-бот с поддержкой GigaChat и YandexGPT

Бот позволяет общаться с двумя российскими нейросетями:
- **GigaChat** (Сбер) – через официальное API
- **YandexGPT** (Яндекс.Облако) – через API‑ключ

Пользователь может в любой момент переключить модель через inline‑клавиатуру.

---

## 🛠 Требования

- Python 3.8+
- Аккаунт в [GigaChat API](https://developers.sber.ru/gigachat) с полученным Authorization Key
- Аккаунт в [Yandex Cloud](https://cloud.yandex.ru/) с созданным сервисным аккаунтом и API‑ключом, а также folder_id
- Токен Telegram‑бота от [@BotFather](https://t.me/botfather)

---

## 📥 Установка и запуск

1. **Клонируйте репозиторий** или скопируйте файлы в папку проекта.

2. **Создайте виртуальное окружение** и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Linux/Mac
   .venv\Scripts\activate         # Windows
Установите зависимости:

bash
pip install -r requirements.txt
Настройте переменные окружения:

Переименуйте .env.example в .env

Вставьте свои токены и ключи (см. инструкции ниже)

Запустите бота:

bash
python bot.py
🔑 Как получить ключи
GigaChat (Сбер)
Перейдите в GigaChat API

Авторизуйтесь через СберБанк ID

В личном кабинете откройте Настройки API → Получить новый ключ

Скопируйте полученный Authorization Key (это длинная строка base64)

Вставьте его в переменную GIGACHAT_AUTH_KEY в .env

YandexGPT (Яндекс.Облако)
Перейдите в Yandex Cloud Console

Создайте каталог (облако), если ещё нет

Перейдите в Сервисные аккаунты → Создать сервисный аккаунт с ролью ai.languageModels.user

Создайте API‑ключ для этого аккаунта и скопируйте его → вставьте в YANDEX_API_KEY

Скопируйте ID каталога из раздела «Обзор» → вставьте в YANDEX_FOLDER_ID

🧠 Использование
Отправьте /start – бот покажет приветствие и предложит выбрать модель.

Нажмите кнопку с нужной моделью – она станет активной.

Просто напишите любой вопрос – бот ответит через выбранную модель.

В любой момент смените модель через команду /switch или повторно выбрав в меню.

📊 Логирование
Все действия логируются в файл bot.log и консоль. Ошибки API записываются с уровнем ERROR.
