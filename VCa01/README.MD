# 🔐 Генератор паролей с графическим интерфейсом

Простое, но мощное приложение для генерации надёжных паролей с возможностью выбора длины и набора символов. Интерфейс выполнен в тёмной теме с красными акцентами, реализована оценка сложности и копирование в буфер обмена.

---

## 📦 Возможности

- Выбор длины пароля (от 4 до 64 символов) через ползунок.
- Настройка используемых символов:
  - строчные буквы (`a–z`)
  - заглавные буквы (`A–Z`)
  - цифры (`0–9`)
  - спецсимволы (`!@#$%^&*()_+-=[]{}|;:,.<>?/~`)
- Генерация пароля по нажатию кнопки.
- Отображение пароля крупным шрифтом.
- Автоматическая оценка сложности (**Слабый / Средний / Хороший / Отличный**).
- Копирование пароля в буфер обмена одним кликом.
- Тёмная тема с красными акцентами (ползунок, кнопки, выделение).

---

## 🛠 Требования

- **Python 3.7** или выше.
- Установленный менеджер пакетов `pip`.

---

## 📥 Установка и запуск

### 🖥 Локально (Windows, Linux, macOS)

1. **Склонируйте репозиторий** или просто скопируйте файлы в папку проекта.

2. **Откройте терминал** в корневой папке проекта.

3. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv .venv
Активируйте его:

Windows (PowerShell):

powershell
.venv\Scripts\Activate.ps1
Windows (CMD):

cmd
.venv\Scripts\activate.bat
Linux / macOS:

bash
source .venv/bin/activate
Установите зависимости из requirements.txt:

bash
pip install -r requirements.txt
Если файла requirements.txt нет, создайте его со следующим содержимым:

text
PyQt5==5.15.9
pyperclip==1.8.2
Затем выполните установку.

Запустите приложение:

bash
python main.py
Если у вас установлено несколько версий Python, используйте py main.py или python3 main.py.

🌐 В Replit (онлайн-среда)
Перейдите на Replit и создайте новый Python-репозиторий.

Вставьте код из main.py в файл с таким же именем.

Создайте файл requirements.txt с указанными выше зависимостями.

В терминале Replit выполните:

bash
pip install -r requirements.txt
Запустите через кнопку Run или командой:

bash
python main.py
Интерфейс откроется в панели Webview (если автоматически не показывается, нажмите «Open in new tab»).

🚀 Использование
Выберите длину – двигайте ползунок влево/вправо.

Отметьте нужные типы символов (минимум один).

Нажмите «Сгенерировать пароль».

Пароль появится в центральном поле, а справа – оценка его сложности.

Нажмите «Копировать в буфер», чтобы скопировать пароль (после генерации кнопка становится активной).

При необходимости измените настройки и сгенерируйте новый пароль.

⚠️ Устранение неполадок
Ошибка ModuleNotFoundError: No module named 'PyQt5'
Убедитесь, что вы активировали виртуальное окружение и выполнили pip install -r requirements.txt.

Попробуйте переустановить PyQt5 вручную:

bash
pip uninstall PyQt5 pyperclip -y
pip install PyQt5==5.15.9 pyperclip==1.8.2
Не открывается графическое окно (особенно в WSL или через SSH)
Для Linux-систем с Wayland может потребоваться установка libxcb-xinerama0 (например, sudo apt install libxcb-xinerama0).

В Replit обязательно используйте режим Webview, а не «Console».

При копировании ничего не происходит
Проверьте, что пароль был сгенерирован (поле не пустое).

В некоторых средах (например, в онлайн-песочницах) доступ к буферу обмена может быть ограничен. В локальной среде проблем быть не должно.
