# 🍳 Бот для поиска рецептов с избранным и рейтингом

Telegram-бот, который ищет рецепты через TheMealDB API, позволяет сохранять понравившиеся рецепты в избранное с оценкой от 1 до 5 ⭐, сортирует их по рейтингу и показывает видеорецепты (YouTube).

---

## 📦 Возможности

- 🔍 **Поиск рецептов** по названию (на русском или английском).
- 🖼 Показ карточки: фото, ингредиенты, инструкция, видеорецепт (если есть).
- ⭐ **Сохранение в избранное** с выбором рейтинга.
- 📚 **Мои рецепты** – список избранных, отсортированный по убыванию рейтинга.
- 🗑 Удаление рецептов из избранного.
- 📋 Логирование всех действий в консоль и файл `bot.log`.

---

## 🛠 Требования

- Python 3.7+
- Установленный `pip`
- Токен бота от [@BotFather](https://t.me/botfather)

---

## 📥 Установка и запуск

### 1. Клонирование / копирование файлов

Создайте папку `recipe_bot` и поместите в неё:
- `bot.py`
- `requirements.txt`
- `.env` (создайте из `.env.example`)

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
3. Настройка токена
Переименуйте .env.example в .env и вставьте свой токен:

text
BOT_TOKEN=1234567890:ABC...
4. Запуск бота
bash
python bot.py
Бот начнёт работу, в консоли появится Бот запущен.

🧠 Использование
Отправьте /start или нажмите кнопку «Start».

Выберите:

🔍 Поиск рецептов – введите название блюда.

📚 Мои рецепты – покажет сохранённые рецепты.

В карточке рецепта нажмите «Сохранить в избранное» и поставьте оценку.

В разделе «Мои рецепты» можно просмотреть полную информацию или удалить рецепт.

📁 Структура базы данных
Используется SQLite (файл recipes.db) с таблицей favorites:

Поле	Тип	Описание
user_id	INTEGER	ID пользователя Telegram
recipe_id	TEXT	ID рецепта из API
recipe_name	TEXT	Название
recipe_thumb	TEXT	URL картинки
recipe_instructions	TEXT	Инструкция
recipe_youtube	TEXT	Ссылка на видео (если есть)
ingredients	TEXT	Список ингредиентов
rating	INTEGER	Оценка пользователя (1–5)
added_at	TIMESTAMP	Дата добавления
