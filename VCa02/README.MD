# 🏦 Ипотечный калькулятор в стиле барокко

Веб-приложение для расчёта аннуитетных платежей по ипотеке с учётом досрочных погашений. Интерфейс выполнен в тёмной эстетике барокко с золотыми акцентами, витиеватыми рамками и декоративными элементами. Поддерживает экспорт графика платежей в Excel.

---

## 📦 Возможности

- **Расчёт аннуитетного платежа** на основе суммы, срока и годовой ставки.
- **Нулевая процентная ставка** – корректный расчёт при 0% (простое деление суммы на срок).
- **Режим «Рассрочка»** – одним чекбоксом обнуляется ставка, поле ввода блокируется.
- **Досрочные платежи** – можно добавить неограниченное количество:
  - **Уменьшить платёж** – пересчитывается ежемесячный платёж на оставшийся срок.
  - **Уменьшить срок** – платёж остаётся прежним, срок сокращается.
- **График платежей** – по месяцам с детализацией: остаток, платёж, проценты, основной долг, остаток, досрочный платёж.
- **Сводка** – общая сумма выплат, переплата, срок.
- **Экспорт в Excel** – скачивание полного графика в формате `.xlsx` с оформленными заголовками.
- **Стиль барокко** – тёмный фон, золото, виньетки, плавные скругления, декоративные символы.

🖥 Использование
Заполните основные поля:

Сумма кредита (₽)

Срок (месяцев)

Годовая процентная ставка (%)

При необходимости включите «Рассрочку» – поле ставки заблокируется и обнулится.

Добавьте досрочные платежи (по желанию):

Скачайте график в Excel – кнопка внизу таблицы.

⚠️ Устранение неполадок
Ошибка ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
Причина: несовместимость Flask 2.2.3 и Werkzeug 3.x.

Решение:
Обновите Flask до версии 3.0.0 (замените в requirements.txt на Flask==3.0.0) и переустановите зависимости:

bash
pip install -r requirements.txt --upgrade
Если хотите оставить старый Flask, добавьте в requirements.txt строку Werkzeug==2.3.8 и выполните переустановку.

Не открывается страница / порт занят
Попробуйте другой порт, изменив последнюю строку в app.py:

python
app.run(debug=True, port=5001)
Ошибка при скачивании Excel
Убедитесь, что у вас есть права на запись в папку проекта. Если проблема persists – проверьте установку openpyxl.
